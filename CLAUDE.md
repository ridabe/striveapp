# Instruções do Projeto — strivePersonalApp

## Graphify (obrigatório)

- **Antes** de alterar código, criar novas features ou fazer qualquer mudança relevante no projeto, consulte primeiro o Graphify (`/graphify`) para entender o contexto, arquitetura e relações existentes no código.
- **Depois**, atualize o Graphify apenas quando a mudança for crítica ou representar uma nova feature que faça sentido estar mapeada na arquitetura (ex: novo módulo, mudança estrutural, nova integração). Não é necessário atualizar para ajustes pontuais, correções pequenas ou refatorações triviais.
- A atualização deve **sempre** ser feita através das habilidades nativas do Graphify (`/graphify --update`), nunca editando manualmente os arquivos gerados em `graphify-out/`.
